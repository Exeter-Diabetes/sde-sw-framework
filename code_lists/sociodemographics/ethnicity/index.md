## Description

Defining ethnicity in EHR. We recommend using codelists from the [HDR UK Phenotype Library](https://phenotypes.healthdatagateway.org/) or [OpenCodelists](https://www.opencodelists.org/), in conjunction with the below advice.

## Rules

* Primary care recorded ethnicity should be used preferentially and supplemented with HES recorded ethnicity where missing as recommended in [https://pmc.ncbi.nlm.nih.gov/articles/PMC4245896/](https://pmc.ncbi.nlm.nih.gov/articles/PMC4245896/).
* It is recommended to align with [UK Government Census categories](https://www.ethnicity-facts-figures.service.gov.uk/style-guide/ethnic-groups/).
* If a patient has multiple different recorded ethnicities, we recommend using the most recently recorded.
