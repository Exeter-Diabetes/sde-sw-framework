## Description

Defining smoking status in EHR. We recommend using codelists from the [HDR UK Phenotype Library](https://phenotypes.healthdatagateway.org/) or [OpenCodelists](https://www.opencodelists.org/), in conjunction with the below advice.

## Rules

* We recommend using the following smoking categories: non-smoker, ex-smoker and active smoker. Active smoker may be further subdivded into light/moderate/heavy (cigarettes/day is sometimes recorded in EHR).
* If most recent code is 'non-smoker' but have previously been recorded as active smoker, then categorise as 'ex-smoker'
