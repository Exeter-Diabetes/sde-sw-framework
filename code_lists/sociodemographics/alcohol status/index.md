## Description

Defining alcohol status in EHR. We recommend using codelists from the [HDR UK Phenotype Library](https://phenotypes.healthdatagateway.org/) or [OpenCodelists](https://www.opencodelists.org/), in conjunction with the below advice.

## Rules

* We recommend using the following alcohol consumption levels: 0 = none, 1 = within limits, 2 = excess, 3 = harmful
* If ever coded with a level 3 code then categorise as level 3.
* If multiple levels coded on most recent date, take the highest level.
