## Description

Identifying and cleaning CGM (sensor and/or transmitter) prescriptions in EHR. We recommend using codelists from the [HDR UK Phenotype Library](https://phenotypes.healthdatagateway.org/) or [OpenCodelists](https://www.opencodelists.org/), in conjunction with the below advice.

## Rules

* Check to make sure the date is within the range expected given the data source and patient DOB and death dates.
